# 쿼카의 배관일지

배관의 오염물을 직접 청소해 얻은 자연 재료로 집과 청소 장비를 성장시키는 브라우저 게임입니다. 현재 구현은 표면 청소부터 4층 정밀 청소와 엔딩까지 이어지는 One Complete Day Vertical Slice입니다.

## 더블클릭 실행 - Windows

[`run-game.cmd`](./run-game.cmd)를 더블클릭하면 기본 브라우저에서 게임이 열립니다.

- Node.js, pnpm, 개발 서버 설치가 필요하지 않습니다.
- Windows에 기본 포함된 PowerShell로 `release/web`을 `http://127.0.0.1:4174`에서 제공합니다.
- 열린 콘솔 창을 유지하면 게임이 실행됩니다. 종료할 때는 콘솔 창을 닫거나 `Ctrl+C`를 누릅니다.
- 로컬에서도 `file://`이 아니라 HTTP로 실행하므로 모듈 로딩과 `localStorage` 동작이 웹 배포 환경과 같습니다.

## 개발 실행

요구 환경: Node.js 22.12 이상, pnpm 11 이상

```powershell
pnpm install
pnpm dev
```

검증과 배포 빌드:

```powershell
pnpm check
pnpm build
```

`pnpm build`는 더블클릭 실행과 웹 배포가 함께 사용하는 `release/web`을 새로 생성합니다.

## 웹 배포

`release/web` 안의 `index.html`과 `assets` 폴더를 그대로 정적 호스팅에 배포합니다.

- GitHub Pages: 게시 루트가 `release/web`의 내용이 되도록 배포합니다.
- itch.io: `release/web` 내부 파일을 ZIP 루트에 넣어 HTML 게임으로 업로드합니다.
- 다른 정적 호스팅: 서버 변환 없이 동일 파일을 업로드합니다.

빌드 설정의 `base: "./"` 때문에 하위 경로 배포에서도 같은 상대 경로를 사용합니다. 로컬 런처는 배포 산출물을 다시 빌드하거나 변환하지 않습니다.

## 현재 플레이 루프

1. 집에서 배관 입구로 이동합니다.
2. WASD/방향키 또는 터치로 쿼카를 움직입니다.
3. 오염물을 선택해 가까이 이동하고 활동력 1을 써서 표면 또는 다음 깊이의 층을 청소합니다. 청소 후에도 같은 구역 안의 쿼카 위치가 유지됩니다.
4. 활동력이 0이면 자동 귀가하고 다음 날이 시작됩니다.
5. 재료로 고정 슬롯에 집 부품을 설치합니다.
6. 행복도에 따라 다음 날 최대 활동력이 증가합니다.
7. 통행 청소율 60%를 달성하면 다음 구역이 열립니다. 깊은 층은 구역 해금 조건에서 제외됩니다.
8. 청소기 2단계로 2층에서 섬유·점토를 얻고, 청소기 3단계와 세정액 조합으로 3층을 청소합니다.
9. 4층은 알맞은 영구 액세서리와 조합 세정액을 함께 장착·선택해야 합니다.
10. `막힌 연결관`은 현재 마지막 구역입니다. 이곳의 통행 청소율 60%는 추가 지역 해금이 아니라 엔딩 조건이며, 청소기 3단계·레시피 5개·행복도 48과 함께 달성하면 엔딩이 열립니다.

## 작업실과 정밀 청소

- 집의 `작업실 열기`에서 청소기 강화, 기초 세정액 제작, 세 방울 조합, 액세서리 제작·장착을 수행합니다.
- 조합 슬롯을 누르면 `물 → 잎 효소 → 풀 발효 → 점토 결합` 순서로 바뀝니다. 물은 무료이며 조합 순서는 무관합니다.
- 성공·실패한 조합은 기록되고, 성공 레시피는 수첩에 영구 저장됩니다.
- 배관 화면의 `세정액` 버튼으로 보유한 완성 세정액을 순환 선택합니다.
- 오염물의 숫자는 현재 제거한 가장 깊은 층입니다. `✓`는 4층까지 완전히 청소한 상태입니다.

## 쿼카의 작은 수첩

- 화면 아래 생각 구름에는 현재 상태에서 가장 가까운 다음 행동 하나가 나타납니다.
- 생각 구름이나 쿼카 얼굴을 누르면 `내 작은 수첩`이 열리고, 부족한 재료의 현재/필요 수량과 실제 획득처를 확인할 수 있습니다.
- `같이 가기`를 누르면 해당 장면으로 이동하고 냄새가 나는 오염물·제작 버튼·집 슬롯을 부드럽게 강조합니다. 행동 자체는 플레이어가 직접 합니다.
- 아직 보지 않은 세정액 정답은 숨겨 두고, 필요한 깊이 층을 한 번 드러낸 뒤에는 쿼카가 정확한 세 방울 조합을 계속 기억합니다.
- 막힌 제작이나 청소를 시도해도 딱딱한 오류로 끝나지 않고, 쿼카가 그 시도에 필요한 준비와 획득 경로를 수첩에 다시 적습니다.
- 별도 친밀도 수치는 없습니다. 날짜, 설치한 집, 청소한 자리, 발견한 조합에 맞춰 쿼카의 속마음과 몸짓이 달라집니다.

모든 성공 명령 뒤에 브라우저 `localStorage`로 자동 저장합니다. 기존 `saveVersion: 1` 저장은 진행도를 유지한 채 버전 2로 자동 변환됩니다. 개발자 콘솔에는 최소 텔레메트리 이벤트만 출력됩니다.

## 현재 리소스 범위

게임 규칙과 전체 진행은 구현되어 있습니다. 캐릭터·오염물·환경은 코드 기반 임시 도형이며, 완성 픽셀 아트·애니메이션·효과음은 콘텐츠 제작 단계에서 교체합니다.
