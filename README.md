# 쿼카의 배관일지

배관의 오염물을 직접 청소해 얻은 자연 재료로 집과 청소 장비를 성장시키는 브라우저 게임입니다. 현재 구현은 표면 청소부터 4층 정밀 청소와 엔딩까지 이어지는 One Complete Day Vertical Slice입니다.

웹에서 바로 플레이: <https://moncheon.github.io/d1/>

## 더블클릭 실행 - Windows

[`run-game.cmd`](./run-game.cmd)를 더블클릭하면 기본 브라우저에서 게임이 열립니다.

- Node.js, pnpm, 개발 서버 설치가 필요하지 않습니다.
- Windows에 기본 포함된 PowerShell로 `release/web`을 `http://127.0.0.1:4174`에서 제공합니다.
- 열린 콘솔 창을 유지하면 게임이 실행됩니다. 종료할 때는 콘솔 창을 닫거나 `Ctrl+C`를 누릅니다.
- 로컬에서도 `file://`이 아니라 HTTP로 실행하므로 모듈 로딩과 `localStorage` 동작이 웹 배포 환경과 같습니다.

## 개발 실행

요구 환경: Node.js 22.13 이상, pnpm 11 이상

```powershell
pnpm install
pnpm dev
```

검증과 배포 빌드:

```powershell
pnpm check
pnpm build
```

`pnpm build`는 더블클릭 실행과 웹 배포가 함께 사용하는 `release/web`을 새로 생성합니다.

## 웹 배포

`master`에 push하면 GitHub Actions가 검사와 빌드를 거쳐 `release/web`을 GitHub Pages에 배포합니다. 서버, 로그인, API 키가 필요하지 않습니다.

- GitHub Pages: `.github/workflows/pages.yml`이 `release/web`을 Pages 아티팩트 루트로 게시합니다.
- itch.io: `release/web` 내부 파일을 ZIP 루트에 넣어 HTML 게임으로 업로드합니다.
- 다른 정적 호스팅: 서버 변환 없이 동일 파일을 업로드합니다.

빌드 설정의 `base: "./"` 때문에 하위 경로 배포에서도 같은 상대 경로를 사용합니다. 로컬 런처는 배포 산출물을 다시 빌드하거나 변환하지 않습니다.

## 플레이 기록과 개인정보

- 일반 URL 접속 시 덤불집 분위기의 시작 화면이 먼저 열립니다. 로그인이나 설치 없이 `처음 시작` 또는 `이어 걷기`를 누르면 플레이할 수 있습니다. 새 게임은 폭우로 보금자리를 잃고 주변을 돌보기 시작한 계기를 2컷 만화 3편으로 보여 주며, 화면을 눌러 넘기거나 건너뛸 수 있습니다.
- 진행 상태는 현재 브라우저의 `localStorage`에만 자동 저장합니다. 서버나 GitHub로 플레이 기록을 전송하지 않습니다.
- 주요 이력만 최근 300개까지 남깁니다. 세션 시작, 청소 완료, 제작·건축, 구역·추억 해금과 하루·단계 완료를 기록하며 자유 입력이나 개인 식별 정보는 수집하지 않습니다.
- 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 도메인·기기에서는 자동 기록을 이어갈 수 없습니다. `배관일지 보관함`에서 JSON을 내려받아 보관하거나 다른 브라우저로 옮길 수 있습니다.
- 새 게임, JSON 가져오기, 복원 전에는 현재 정상 기록을 이전 기록 1개로 보관합니다. 복원하면 현재 기록과 백업이 서로 바뀝니다.
- JSON 파일은 `format: "quokka-pipe-cleaner"`, `bundleVersion: 1` 형식이며 주인공 이름, 진행 상태, 시작 이야기 완료 여부, 저장 시각, 세션 수와 주요 이력을 포함합니다. 기존 `GameState` JSON과 `saveVersion: 1~7`도 가져올 수 있습니다.
- 가져오기는 2MB 이하만 허용하고 형식·버전·게임 상태를 검증한 뒤 요약 화면에서 사용자가 확정해야 적용합니다. 실패하거나 파일 선택을 취소하면 현재 기록을 바꾸지 않습니다.

## 현재 플레이 루프

1. 집에서 격자형 배관 지도로 이동해 열린 원통을 선택합니다.
2. 선택한 관은 아래쪽 절반을 잘라낸 내부로 보이며, WASD/방향키 또는 터치로 쿼카를 부드럽게 움직입니다.
3. 청소 가능한 오염물을 선택하면 가까이 이동합니다. 낙엽·풀뿌리·흙의 첫 표면과 첫 희귀 4층에서만 2~4초의 무실패 손동작이 열리고 모든 재료를 2배로 얻습니다. 도움 없이 마치면 대표 재료도 하나 더 받으며, 나머지 청소는 짧은 생활 동작으로 바로 끝납니다.
4. 활동력이 0이면 재료를 들고 귀가합니다. 지을 수 있는 집 부품이 있으면 저녁에 손수 짓고, 없다면 쿼카가 망설이지 않고 잠자리에 듭니다.
5. 중앙 생활공간과 반구형 가지 골조를 둘러싼 9개 앵커를 꾸밉니다. `꾸미기` 모드에서 부위마다 세 가지 재료 모습을 비용·행복도·쿼카의 생활 반응과 함께 비교하고, 기존 부품은 전액 회수하거나 다른 모습으로 교체할 수 있습니다.
6. 완성한 집은 조명과 쿼카의 반응을 바꾸고 행복도를 높입니다. 행복도는 다음 날 최대 활동력에 직접 반영됩니다.
7. 침대나 임시 낙엽 자리에서 실제로 잠든 뒤에만 다음 날이 시작됩니다.
8. 배관 입구의 통행 청소율 60%를 달성하면 유기물 중심의 `굽은 배수로`와 광물 중심의 `막힌 연결관`이 함께 열립니다. 방문 순서는 자유이며 깊은 층은 구역 해금 조건에서 제외됩니다.
9. 청소기 2·3단계, 세정액 조합과 영구 액세서리로 지정된 핵심 오염의 4층까지 청소합니다.
10. 세 구역의 통행 청소율 100%와 핵심 심층 오염 3곳의 완전 청소가 현재 `배관망 1단계` 완료 조건입니다. 다음 단계의 이야기와 콘텐츠는 아직 포함하지 않습니다.

## 작업실과 정밀 청소

- 집의 `작업실 열기`에서 청소기 강화, 기초 세정액 제작, 세 방울 조합, 액세서리 제작·장착을 수행합니다. 활동력이나 재료가 모자라면 버튼 자체에 지금 막힌 이유가 표시됩니다.
- 조합 슬롯을 누르면 `물 → 잎 효소 → 풀 발효 → 점토 결합` 순서로 바뀝니다. 물은 무료이며 조합 순서는 무관합니다.
- 성공·실패한 조합은 기록되고, 성공 레시피는 수첩에 영구 저장됩니다.
- 배관 화면의 `세정액` 버튼에서 보유 용액을 고르거나 곧바로 작업실로 이동해 새 용액을 만들 수 있습니다. 배관에서 들어온 작업실은 원래 구역과 쿼카 위치를 기억하며, 배합 성공 시 새 용액을 선택한 채 돌아옵니다.
- 오염물의 숫자는 현재 제거한 가장 깊은 층입니다. `✓`는 4층까지 완전히 청소한 상태입니다.
- 활동력·청소기·액세서리·세정액이 부족한 대상은 이동이나 미니게임 전에 막힌 이유를 알려 주고, 휴식·작업실 수첩·세정액 선택으로 바로 이어지는 버튼을 보여 줍니다.

## 쿼카의 작은 수첩

- 화면 아래 생각 구름에는 현재 상태에서 가장 가까운 다음 행동 하나가 나타납니다.
- 생각 구름이나 쿼카 얼굴을 누르면 `내 작은 수첩`이 열리고, 부족한 재료의 현재/필요 수량과 실제 획득처를 확인할 수 있습니다.
- `같이 가기`를 누르면 해당 장면으로 이동하고 냄새가 나는 오염물·제작 버튼·집 생활 앵커를 부드럽게 강조합니다. 행동 자체는 플레이어가 직접 합니다.
- 아직 보지 않은 세정액 정답은 숨겨 두고, 필요한 깊이 층을 한 번 드러낸 뒤에는 쿼카가 정확한 세 방울 조합을 계속 기억합니다.
- 막힌 제작이나 청소를 시도해도 딱딱한 오류로 끝나지 않고, 쿼카가 그 시도에 필요한 준비와 획득 경로를 수첩에 다시 적습니다.
- 별도 친밀도 수치는 없습니다. 날짜, 설치한 집, 청소한 자리, 발견한 조합에 맞춰 쿼카의 속마음과 몸짓이 달라집니다.
- 첫 청소·첫 건축·첫 분기 방문·집에서의 첫밤 같은 장면은 날짜와 함께 `공동 추억`에 남고, 집 부품에 따라 쿼카가 냄새 맡기·풍경 듣기·침대에서 몸 말기 같은 생활 포즈를 보입니다.
- 평상시 수첩은 `집 돌보기`와 `배관 탐색하기` 중 두 의도를 제안합니다. 처음 배우는 행동과 막힌 행동에만 정확한 단일 해결 경로를 보여 줍니다.

모든 성공 명령 뒤에 브라우저 `localStorage`로 자동 저장합니다. 시작 화면에서 지은 이름과 시작 이야기 완료 여부도 함께 저장되며 공백 이름도 허용합니다. 기존 `saveVersion: 1`~`6` 저장은 진행도를 유지한 채 버전 7로 자동 변환되고, 기존 이용자에게 시작 이야기를 강제로 다시 보여 주지 않습니다. 과거 20슬롯 집은 카테고리별 대표 부품을 9개 생활 앵커로 옮기고 초과 부품의 재료를 전액 환급합니다. 활동력을 모두 쓴 이전 저장은 잠들기 전 저녁 상태로 복구됩니다. 설정에서 소리, 간편 청소, 모션 감소와 배관일지 내보내기·불러오기를 이용할 수 있습니다.

## 현재 리소스 범위

집·유기물 배관·광물 배관 배경, 뒤벽·측벽·낮은 전면 턱이 이어진 앞면 절개 반구 외피, 18종 집 부품, 12개 쿼카 생활·작업 포즈와 2컷 시작 만화 3편을 따뜻한 픽셀 아트로 구성했습니다. 외피 장식은 반구 곡면에 겹치고 침상·정원·길은 중앙 바닥에 접지 그림자를 두며, 평상시에는 슬롯 표시 없이 실제 생활 장면만 보입니다. 꾸미기 모드에서만 앵커가 나타납니다. 오염 상태와 일부 UI 아이콘은 데이터 기반 코드 도형을 유지합니다. 시작 만화의 배경음악과 3초 이내 효과음은 외부 음원이나 네트워크 요청 없이 브라우저 Web Audio로 실시간 합성하며, 동작·건축·추억·수면에도 가벼운 Web Audio 피드백과 장면 연출을 사용합니다.
