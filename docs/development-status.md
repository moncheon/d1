# 개발 상태와 게이트

## 현재 단계

`Product Hypothesis → Core Loop Prototype → Data-driven Walking Skeleton → One Complete Day Vertical Slice`

구현된 흐름은 `Home → Pipe Map → Cylindrical Workplace → Clean → Return Home → Hand-build → Sleep → Next Day → Step 1 Complete`입니다. 수치, 층 요구조건, 보상, 배합, 액세서리와 배관·집 배치는 JSON 데이터에서 읽습니다.

## 구현 완료

다음 항목이 게임 상태, 화면, 저장과 테스트에 연결되어 있습니다.

1. 청소기 2·3단계와 오염 1~4층
2. 액체 4종, 순서 무관 3칸 조합, 실패 힌트
3. 발견 레시피 수첩, 통행/정밀 청소율 분리
4. 영구 액세서리 3종의 제작·장착
5. 희귀 재료와 행복도 48까지의 도달 가능한 경제
6. 입구 60%에서 유기물·광물 두 분기 동시 해금과 전 구역 100%·핵심 심층 3곳의 1단계 완료 판정
7. saveVersion 1·2·3·4에서 5로의 저장 마이그레이션, 20슬롯 집의 9앵커 변환·초과 재료 환급과 저녁 상태 복구
8. 쿼카의 상태 기반 다음 행동, 부족 재료·획득처 수첩, 목적지 이동·강조
9. 제작 버튼의 활동력·재료·장비 단계별 비활성 사유 표시
10. 배관 세정액 선택창에서 작업실 왕복, 위치 보존 및 완성 용액 자동 선택
11. 활동력 소진 뒤 설치 가능한 집 부품이 없을 때 귀가 후 자동 취침
12. 격자 배관 지도, 미개척 원통과 선택 구역의 절개된 내부
13. 청소 동작, 귀가, 건축 손작업, 행복도 환경 변화와 수면 연출
14. 오염 3종의 첫 표면·첫 희귀 4층에만 나오는 무실패 손동작, 전체 재료 2배와 정성 청소 추가 보너스
15. 청소 전 활동력·장비·액세서리·세정액 사전 판정과 휴식·수첩·용액 선택 해결 경로
16. 중앙 생활공간과 앞면 절개 반구 외피를 이루는 9개 앵커, 부위별 3종·총 18종 픽셀 오브젝트와 원자적 교체·전액 회수
17. 뒤벽이 채워진 가지 반구와 외피에 밀착되는 재료 장식, 유기물·광물 배관 픽셀 디오라마와 쿼카 12개 생활·작업 포즈
18. 전체 화면 최소 12px 캔버스 글자, 공통 버튼·제목 크기와 대비 정비
19. 수치 없는 공동 추억, 평상시 2개 의도·막힘 시 단일 해결 경로
20. 소리·모션 감소·간편 청소 설정과 가로 모바일/세로 회전 안내
21. 덤불집 분위기의 시작 화면, 브라우저 자동 저장, 주요 이력 최근 300개와 현재/백업 기록 요약
22. 검증·미리보기·무변경 실패 보장을 갖춘 JSON 내보내기/가져오기와 구버전 저장 호환
23. `master` 검사·빌드 후 `release/web`을 게시하는 GitHub Pages Actions 배포

2. 실제 20~40분 완주 시간과 두 분기별 재료 병목 측정
3. 조합 실패율, 청소 도움 사용률, 첫 활동력 증가 시점, 분기 선택과 구역 이탈 지점 기록
4. 목표 플레이어가 집 변화와 쿼카 생활 반응을 자발적으로 기억하는지 관찰
5. 가로 모바일 터치와 저사양 기기 프레임 확인

## 기능 삭제 순서

일정이 밀리면 다음 순서로 줄입니다.

1. 장식 종류와 애니메이션 프레임
2. 액세서리 3종 중 2종
3. 세 번째 구역의 깊은 오염
4. 수동 배합 실험 UI(권장 레시피 선택은 유지)
5. 주요 이력의 세부 항목

청소→귀가→집→수면→다음 날 활동력, 60% 구역 해금, 100% 1단계 완료, 자동 저장은 삭제하지 않습니다.
