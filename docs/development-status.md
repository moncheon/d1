# 개발 상태와 게이트

## 현재 단계

`Product Hypothesis → Core Loop Prototype → Data-driven Walking Skeleton → One Complete Day Vertical Slice`

구현된 흐름은 `Home → Workplace → Surface/Deep Clean → Reward → Workshop → Build → Day End → Next Day → Ending`입니다. 수치, 층 요구조건, 보상, 배합, 액세서리와 배치는 JSON 데이터에서 읽습니다.

## 구현 완료

다음 항목이 게임 상태, 화면, 저장과 테스트에 연결되어 있습니다.

1. 청소기 2·3단계와 오염 1~4층
2. 액체 4종, 순서 무관 3칸 조합, 실패 힌트
3. 발견 레시피 수첩, 통행/정밀 청소율 분리
4. 영구 액세서리 3종의 제작·장착
5. 희귀 재료와 행복도 48까지의 도달 가능한 경제
6. 네 가지 완료 조건과 엔딩 후 계속 플레이
7. saveVersion 1에서 2로의 저장 마이그레이션

## 다음 게이트: Playtest + Telemetry

1. 첫 3분 온보딩과 하루 종료 정산 연출
2. 대표 픽셀 아트, 청소·획득·건축 효과음
3. 실제 20~40분 완주 시간과 재료 병목 측정
4. 조합 실패율, 첫 활동력 증가 시점, 구역 이탈 지점 기록
5. 모바일 세로 화면 안내와 저사양 기기 프레임 확인

## 기능 삭제 순서

일정이 밀리면 다음 순서로 줄입니다.

1. 장식 종류와 애니메이션 프레임
2. 액세서리 3종 중 2종
3. 세 번째 구역의 깊은 오염
4. 수동 배합 실험 UI(권장 레시피 선택은 유지)
5. 저장 내보내기/가져오기

청소→재료→집→다음 날 활동력, 60% 구역 해금, 자동 저장은 삭제하지 않습니다.
